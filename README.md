# Getting-a-Good-Night-sleep


## About the Project
In this project, I analyzed sleep and lifestyle data to explore the relationship between occupation, sleep duration, sleep quality, and sleep disorders.

## Questions
- Which occupation has the lowest average sleep duration?
- Which occupation has the lowest average sleep quality?
- Do the same occupations have the lowest sleep duration and sleep quality?
- What is the ratio of people diagnosed with insomnia in each BMI category?

## Dataset
The project uses `sleep_health_data.csv`, which contains sleep and lifestyle information for 374 individuals.

## Tools Used
- Python
- Pandas

## What I Learned
- Grouping data and calculating averages.
- Finding minimum values in a dataset.
- Comparing results using conditions.
- Calculating ratios using Pandas.
- Creating dictionaries to store analysis results.

## Goal
The goal of this project was to practice data analysis and understand patterns in sleep health data.
